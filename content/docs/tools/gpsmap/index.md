# 사진 GPS 경로 지도화

여러 장의 사진을 한 번에 선택하면, 각 사진에 저장된 GPS 위치 정보를 읽어 이동 경로를 지도 위에 표시합니다.

{{< gpsmap >}}

사진을 촬영한 순서(촬영 날짜 기준)대로 경로가 이어집니다. GPS 정보가 없는 사진은 지도에 표시되지 않으며, 별도로 몇 장인지 안내됩니다.
