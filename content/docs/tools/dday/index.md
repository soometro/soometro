# D-Day 디데이 계산기

기준일은 오늘 날짜로 자동 입력됩니다. 목표일만 달력에서 선택하면 D-Day가 바로 계산됩니다.

{{< dday >}}

특정 날짜까지 남은 날짜를 확인할 때 사용할 수 있습니다. 시험일, 여행일, 퇴직일, 기념일, 프로젝트 마감일 등에 활용할 수 있습니다.
