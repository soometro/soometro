# 텍스트 중복 제거

같은 내용의 줄이 여러 번 반복되는 텍스트에서 중복된 줄을 제거합니다.

입력 순서는 그대로 유지하면서 처음 등장한 내용만 남깁니다.

{{< textdeduplicate >}}

## 텍스트 중복 제거 방법

텍스트를 한 줄에 하나씩 입력하면 동일한 줄의 중복이 자동으로 제거됩니다.

예를 들어 다음과 같이 입력합니다.

```text
사과
바나나
사과
오렌지
바나나
